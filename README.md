IoT project focused on the automation and monitoring of photoperiod in protected cultivation environments.

**Technologies:** ESP32 · MQTT · Python · FastAPI · PostgreSQL · React

---

### LUNETRAS

Educational web system focused on monitoring and supporting the development of children's reading and writing skills.

**Technologies:** React · Vite · JavaScript · HTML · CSS

### SigeLeite

Academic and applied technology project developed during my internship, focused on the use of IoT technologies in milk production.

The project integrates embedded systems and sensors to support the monitoring and automation of activities related to dairy production.

The project resulted in a scientific article that was accepted for publication/presentation.

**Technologies:** ESP32 · RFID · Wi-Fi · Sensors · IoT
